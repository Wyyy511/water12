# WaterPulse AI Agent V9.6 — 企业决策报告版

V9.6 根据教师反馈，重点重构最终导出报告。

WaterPulse 面向采购、供应链、ESG 与风险管理人员。企业提供原材料、供应节点和采购结构后，系统完成数据核验、确定性水风险计算、供应链压力测试，再由 DeepSeek AI 对结果进行企业可读的风险评估、结论和管理建议。

最终报告不再展示开发过程、字段映射过程、程序工作流、接口或日志。正文只回答：
1. 当前水风险如何；
2. 最大风险供应地在哪里；
3. 风险主要来自什么；
4. 关键供应地中断后会怎样；
5. 企业应该优先采取什么行动。

技术版本、运行编号和一致性校验仅放在附录。
